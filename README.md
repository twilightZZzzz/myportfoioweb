# Портфолио «Кинематограф»

Статический сайт: HTML + CSS + JS, анимации на GSAP + ScrollTrigger, плавный скролл на Lenis (всё с CDN, сборка не нужна).

## Запуск локально

```bash
python3 -m http.server 5173 --directory portfolio
```

Открыть http://localhost:5173

## Что заменить на своё

| Что | Где |
|---|---|
| Имя, почта, соцсети | `index.html` — поиск по «Имя Фамилия», `hello@yourname.design`, ссылки в блоке `.contact__links` |
| Цифры (лет, проектов, наград, %) | `index.html`, атрибуты `data-count` в блоке `.stats` |
| Услуги, отзывы, титры | `index.html`, блоки `.services`, `.critics`, `.credits` |
| Кейсы: тексты, цифры, цвета | `js/cases.js` — массив `CASES` |
| Скриншоты кейсов | положить в `img/`, в кейсе указать `cover: 'img/имя.jpg'` и `gallery: ['img/1.jpg', ...]` |
| Акцентный цвет | `css/style.css`, переменная `--ember` |

## Пасхалки и детали

- Обратный отсчёт киноплёнки при первом входе за сессию (Esc — пропустить)
- Прожектор в hero проявляет заголовок; без мыши свет гуляет сам, на телефоне идёт за пальцем
- Клавиша **G** (или кнопка в футере) — показать модульную сетку
- Каждый кейс открывается по ссылке `#case-<id>`, кнопка «назад» в браузере закрывает кейс
- Учитывается `prefers-reduced-motion`: при включённой настройке анимации отключаются

## Деплой

Папку `portfolio/` можно залить на Vercel, Netlify или GitHub Pages как есть.
