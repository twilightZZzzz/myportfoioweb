# Сайт full-stack веб-разработчика

Astro 7 + TypeScript, деплой на Vercel. Заявки с формы приходят в Telegram.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Локальный сервер на http://localhost:4321 |
| `SHOW_DRAFTS=1 npm run dev -- --ignore-lock` | То же, но с черновиками проектов (например, образцом кейса) |
| `npm run check` | Проверка типов (`astro check`) |
| `npm run lint` | ESLint |
| `npm test` | Unit-тесты (Vitest): валидация формы, антиспам, rate limit, данные |
| `npm run test:e2e` | E2E (Playwright, десктоп + телефон): маршруты, меню, форма, фильтры, 404, анимации |
| `MOTION=1 npx playwright test motion-shots` | Кадры анимаций для визуальной проверки → `qa-shots/motion/` |
| `npm run build` | Production-сборка |

Первый запуск e2e: `npx playwright install chromium`.

## Перед публикацией — обязательно

Сборка **не пройдёт**, пока не заполнено (это защита от публикации заглушек):

1. `src/data/site.ts` — `name` (настоящее имя), `contacts.telegram` и/или `contacts.email`, `legal.operatorName` (ФИО для политики ПДн).
2. Переменная окружения `SITE_URL` — домен сайта.

Желательно:

- `about.experience` — честное описание опыта своими словами (пустое — абзац не выводится);
- `stack` — технологии, с которыми реально работаешь (пустое — блок не выводится);
- `photo` — фото в `src/assets/about/`, например `photo: 'about/photo.jpg'`;
- проверить тексты услуг (`src/data/services.ts`), FAQ (`src/data/faq.ts`) и диапазоны бюджета в форме (`src/lib/contact/validate.ts`) — это формулировки по умолчанию, они должны совпадать с тем, как ты работаешь.

## Переменные окружения (Vercel → Settings → Environment Variables)

См. `.env.example`.

- `SITE_URL` — домен.
- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather.
- `TELEGRAM_CHAT_ID` — куда слать заявки (свой chat id или id группы). Боту нужно хотя бы раз написать `/start`.

Без токена форма честно отвечает «временно не работает» и показывает прямые контакты — ложного «успеха» не будет.

## Как добавить проект

1. Скопировать `src/content/projects/obrazec-keisa.md` в новый файл. Имя файла станет адресом: `/projects/<имя>`.
2. Заполнить поля. Необязательные можно удалить: соответствующие блоки на странице не появятся.
3. Указать `status: demo` или `status: commercial`. Если задача придумана для демонстрации — `challengeSimulated: true`.
4. Картинки положить в `src/assets/projects/<имя>/` — Astro сам их оптимизирует.
5. Удалить `draft: true`.

Пока нет ни одного опубликованного проекта:
- раздел «Избранные проекты» на главной скрыт;
- вторая кнопка в hero ведёт на «Услуги», а не в пустой раздел;
- `/projects` показывает честное пустое состояние.

Отзывы — только настоящие, в `src/data/testimonials.ts`. Пока массив пуст, блок отзывов не выводится.

## Движение и визуал

Кинематографический слой — `src/scripts/motion.ts` (GSAP + ScrollTrigger + SplitText + Lenis):
отсчёт киноплёнки при первом входе на главную за сессию, прожектор в hero, раскрытие заголовков по строкам,
«расшифровка» подписей, бегущая строка от скорости скролла, манифест по словам, закреплённая сцена
«сайт → форма → Telegram → статус», горизонтальная плёнка проектов, линия процесса, 3D-наклон карточек,
курсор с подписями, магнитные кнопки, шторка между страницами, зерно плёнки, титры в подвале.

При `prefers-reduced-motion` всё это отключается, контент остаётся видимым. Если скрипт не загрузился,
через 4 секунды страница сама показывает всё без анимаций.

Разметка для анимаций: `data-split` (заголовок по строкам), `data-scramble` (моно-подпись),
`data-reveal` (появление блока), `data-magnetic`, `data-cursor="Подпись"`, `data-tilt`, `data-glow`.

## Устройство

```
src/
  data/            типы моделей, данные владельца, услуги, FAQ, отзывы
  content/projects кейсы (Markdown + frontmatter, схема в src/content.config.ts)
  lib/contact/     валидация (общая для браузера и сервера), антиспам, rate limit, Telegram
  pages/           маршруты; /services/[slug] и /projects/[slug] — шаблоны
  pages/api/contact.ts  серверная обработка формы (работает и без JS)
  components/      Header с мобильным меню, формы, карточки, FAQ, схемы, галерея
tests/unit, tests/e2e
```

### Защита формы

- проверка всех полей на сервере, неизвестные значения отклоняются;
- скрытое поле-ловушка и проверка времени заполнения;
- ограничение частоты: 5 заявок за 10 минут с одного IP. Хранилище в памяти функции, поэтому на Vercel это защита от простого флуда. Для строгого лимита добавь правило Rate Limiting в Vercel Firewall на `/api/contact`;
- токен бота читается только на сервере (`astro:env`, `access: 'secret'`).

## Юридическое — проверить с юристом

Выбран хостинг Vercel и доставка в Telegram, поэтому данные из формы обрабатываются за пределами РФ. В политике (`/privacy`) и согласии (`/consent`) это указано прямо. Для соответствия 152-ФЗ, вероятно, понадобятся:

- уведомление Роскомнадзора об обработке ПДн;
- уведомление о трансграничной передаче;
- проверка требования о первичной записи данных граждан РФ в базы на территории РФ.

Вариант без этих рисков — российский VPS с хранением заявок в РФ. Архитектура позволяет переключиться: обработчик заявки отделён от транспорта (`src/lib/contact/handler.ts`).
